# Celebal Technologies – SQL Practical Assignments

This repository contains my weekly SQL practical assignments completed as part of the **Celebal Technologies (CLE) Training Program**.

The assignments focus on developing practical SQL and MySQL skills through database creation, data manipulation, queries, stored procedures, functions, views, and advanced SQL concepts.

## 📚 Weekly Assignments

### Week 1 – SQL Fundamentals

Topics covered:
- Database and table creation
- SQL constraints
- Data insertion and manipulation
- SELECT queries
- Filtering and sorting
- Aggregate functions
- GROUP BY and HAVING
- SQL joins
- Subqueries

### Week 2 – Advanced SQL Concepts

Topics covered:
- Stored Procedures
- User-Defined Functions
- Error Handling
- Views
- Common Table Expressions (CTEs)
- Window Functions
- Advanced SQL queries

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/GauravGaikwad037/cle-assignment.git
   ```

2. Open the project folder in VS Code.

3. Install the required VS Code extensions:
   - Python
   - Jupyter

4. Ensure MySQL Server is installed and running.

5. Open the required weekly `.ipynb` notebook.

6. Configure your MySQL connection details securely in your local environment.

7. Select the appropriate Python kernel and execute the notebook cells sequentially.

## 🎯 Objective

The objective of these assignments is to strengthen SQL concepts, understand database operations, and gain hands-on experience in writing and executing SQL queries using MySQL.
